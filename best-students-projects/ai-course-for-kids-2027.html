Recommended pace: about 5 learning days per week, 1.5–2 hours per day (roughly 7.5–10 hours weekly). This is a proposed schedule—not a guarantee that every student will master every topic within six months.

Suitable for learners aged 9+ with supervision and simplified projects where needed. Advanced backend, mobile, security, and AI-agent modules may need extra time or support for younger beginners.

Six Stages · Month by Month

Month 1 · Weeks 1–4 Beginner

AI, Coding Foundations & Web Design

Stage 1: Learn how software works — AI as a tutor, basic code, first browser apps.

Week 1 — AI-assisted development · Deliverable: Calculator
Week 2 — HTML & structure · Deliverable: Profile website
Week 3 — CSS & responsive design · Deliverable: Landing page
Week 4 — JavaScript foundations · Deliverable: Quiz or number game

Assessment: Make a small change without copying a full solution, explain main code, fix at least one bug.

Month 2 · Weeks 5–8 Beginner → Intermediate

JavaScript Applications & Programming Logic

Stage 2: Become a problem solver — apps that respond to users and manage data.

Also: break problems into tasks, documentation, Git & GitHub basics. Challenge: build from a written specification without asking AI for the entire solution at once.

Month 3 · Weeks 9–12 Intermediate

Backend, Databases & Full-Stack

Stage 3: Build real web applications — servers, APIs, and databases.

Proposed main stack: HTML/CSS/JS · Node.js & Express · MongoDB · VS Code · Git/GitHub · suitable hosting.

Auth (hashing, protected routes, env vars) after basic server/DB skills. Milestone: input → backend → database → retrieve.

Month 4 · Weeks 13–16 Intermediate

Platform Projects, APIs & Applied AI

Stage 4: Build applications people can use — accounts, search, external APIs, AI features.

Week 13 — Auth, roles, sessions/tokens
Week 14 — Search, filter, uploads · Marketplace
Week 15 — External APIs · Weather/currency dashboard
Week 16 — AI APIs · Content assistant / summarizer

Flagship project choices (original branding only)

  • • Property marketplace
  • • Freelance marketplace
  • • Learning platform
  • • E-commerce prototype

Students must not copy proprietary assets or present a learning project as an official service.

Month 5 · Weeks 17–20 Intermediate intro

Python, AI Tools & Agent Workflows

Stage 5: Move from applications to automation — Python essentials and careful AI workflows.

WeekFocusProject
17Python syntax basicsCLI utility or quiz
18Files, JSON, CSV, HTTPDocument/data tool
19AI APIs & promptsResume / content assistant
20Multi-step workflowsJob application or research flow

AI agent levels (teach in order)

  • Level 1 — AI tool: prompt → result
  • Level 2 — Automated workflow: defined multi-step process
  • Level 3 — Tool-using agent: chooses tools, checks goals, asks human approval for consequential actions

Students should not build unsupervised systems that send messages, contact strangers, make purchases, or modify important data.

Month 6 · Weeks 21–24 Applied development

Flutter Mobile, Deployment & Capstone

Stage 6: Turn learning into a portfolio — intro Flutter + final showcase.

Week 21 — Dart, widgets, navigation
Week 22 — Forms, state, HTTP
Week 23 — Backend client, auth basics
Week 24 — Capstone, demo, documentation

Capstone options

  • A — Marketplace system (web + mobile API client)
  • B — AI career assistant (CV feedback, privacy-aware)
  • C — Learning management app (lessons, quizzes, optional AI tutor)

Judged on functionality, code understanding, reliability, documentation, and demo—not only UI polish.

Expected Outcomes After Six Months

Target foundations for further study—not a claim of expertise in every technology listed.

  • ✔ Responsive websites (HTML, CSS, JavaScript)
  • ✔ Interactive browser apps & debugging
  • ✔ Basic backend API + database
  • ✔ Small full-stack web application
  • ✔ External API or AI service integration
  • ✔ Python automation & simple AI workflows
  • ✔ Introductory Flutter mobile app
  • ✔ GitHub portfolio & project demos
  • ✔ Awareness of security, privacy & responsible AI

Tools & safety policy (summary)

Primary path: VS Code, Git/GitHub, Node/Express, MongoDB, Python, Flutter. AI assistants used as tutors—not to replace thinking. Before each cohort, tools and API terms are verified. Students under 18 need appropriate adult supervision; personal data is not exposed through public repos or social media for basic lessons.

Never require payment details merely to complete a basic lesson.
