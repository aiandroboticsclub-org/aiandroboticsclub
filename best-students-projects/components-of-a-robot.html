Inside a Robot

What is actually inside a robot — and what kids can imagine. A robot is a combination of electronics + programming that helps machines think, sense, and act.

Key Electronic Components

Simple explanations you can remember and share.

Resistors

Controls the flow of electricity so components don’t get damaged.

Capacitor

Stores energy and releases it quickly when needed — but not like batteries.

Diodes

One Way Traffic

Allows electricity to flow in only one direction.

Transistor

Works like a switch or amplifier to control signals at certain conditions.

Integrated Circuit

Packed Brain

A small chip that contains many electronic components inside.

Microcontroller

The “brain” of the robot that runs programs and makes decisions.

Sensors

Help the robot see, hear, and feel the environment — so it can react to the world around it.

Remember This

A robot is a combination of electronics + programming that helps machines think, sense, and act.
