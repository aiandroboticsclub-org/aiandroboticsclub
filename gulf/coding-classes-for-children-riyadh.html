Variables and Data Types: Storing Information Inside Digital Memory Boxes

Before loops and games, children need a mental model of memory. A variable is a labelled box. Coding classes for children in Riyadh can make that metaphor concrete online: write a name, store a number, print it, change it, print again.

Why the box metaphor works

If the box is labelled age, what belongs inside? Mixing types causes errors that train careful thinking.

Data types without intimidation

A score is a number. A name is text. Game over is true or false.
