1. Introduction: Why String Cleaning Is Critical

Client text rarely arrives standardized. Common problems:

  • Inconsistent casing — "ELECTRONICS" vs "electronics" (Python is case-sensitive)
  • Leading/trailing spaces — e.g. " Shoes " breaks grouping and filters
  • Unwanted separators — hyphens and symbols used inconsistently

Pandas string tools live under the .str accessor. A typical pipeline:

"  HOME-APPLIANCES  "
  → .str.strip()    → "HOME-APPLIANCES"
  → .str.lower()    → "home-appliances"
  → .str.replace()  → "home appliances"

2. Setup: Dirty Text in a DataFrame

import pandas as pd

data = {
    "Product_ID": [101, 102, 103, 104],
    "Category": [
        "  ELECTRONICS  ",          # whitespace + uppercase
        "home-appliances",         # hyphen
        "CLOTHING-ACCESSORIES  ",  # uppercase, hyphen, trailing space
        "  electronics"            # leading space + lowercase
    ]
}

df = pd.DataFrame(data)
print(df)

Rows 0 and 3 are the same category but do not match until cleaned. Rows 1 and 2 need hyphens turned into spaces.

3. Case and Whitespace: .str.lower() and .str.strip()

  • .str.lower() — all letters lowercase for uniform matching
  • .str.strip() — remove leading and trailing spaces

Chain them and store in a new column:

df["Category_Clean"] = df["Category"].str.strip().str.lower()
print(df[["Category", "Category_Clean"]])

Result: whitespace gone and every entry lowercase (e.g. both electronics rows align).

4. Replacing Characters with .str.replace()

df["Category_Clean"] = df["Category_Clean"].str.replace("-", " ")
print(df[["Category", "Category_Clean"]])

"home-appliances" → "home appliances"; "clothing-accessories" → "clothing accessories". Text is then lowercase, trimmed, and free of hyphens.

Lesson Q&A

Python string matching is case-sensitive. Mixed or all-caps values like "ELECTRONICS" and "electronics" are treated as different. .str.lower() standardizes the column so comparison, grouping, and category matching work reliably.

.str.strip() removes leading and trailing whitespace. You can chain methods in one line, e.g. df['Category'].str.strip().str.lower(), to trim and lower-case in a single step.

.str.replace(old, new) finds the old substring and swaps it for the new one. For example, df['Category'].str.replace('-', ' ') turns "home-appliances" into "home appliances".
