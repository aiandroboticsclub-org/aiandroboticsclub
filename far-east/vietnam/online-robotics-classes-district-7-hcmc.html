1. What “Linear” Means

Linear regression applies when the relationship between inputs and outputs is linear. If the relationship is non-linear, this algorithm will not fit well and other methods should be used instead.

2. Defining a Linear Relationship

A change in the input produces a proportional change in the output:

  • Directly proportional: input up → output up (or both down)
  • Inversely proportional: input up → output down (or the reverse)

The pattern is consistent rather than random fluctuation.

3. Real-World Examples

  • Study hours vs grades: more hours tend to yield proportionally better scores
  • Temperature vs ice cream sales: warmer days tend to lift sales in proportion
  • Marketing budget vs revenue: higher spend often tracks higher sales proportionally

4. Check the Data First

Before training, inspect whether a linear pattern exists. If it does, linear regression is appropriate. If not, choose algorithms built for non-linear structure.

5. Simple vs Multiple Linear Regression

Simple (one feature): y = mx + b

Multiple (many features, typical client tables):

y = b + m₁x₁ + m₂x₂ + m₃x₃ + …

Each input column is a feature with its own slope; b remains a single intercept. The form scales to any number of features as long as the overall relationship stays linear.
