1. Collecting User Data

Interactive apps need two-way flow: visitors submit data and the server processes it. This lesson covers HTML forms, POST handling in Flask, reading form fields, and checking requests in the browser Network tab.

2. GET vs POST

  • GET — retrieve data (loading a page)
  • POST — send data to the server (form submit, credentials, ML payloads)

3. HTML Form (input.html)
  • action="/submit" — where data is sent
  • method="POST" — how it is sent
  • name="username" — key Flask uses to read the value

4. Flask Backend

from flask import Flask, render_template, request

app = Flask(__name__)

@app.route("/input")
def input_page():
    return render_template("input.html")

@app.route("/submit", methods=["POST"])
def submit():
    name = request.form["username"]
    return f"Hello {name}"

if __name__ == "__main__":
    app.run(debug=True)

5. Test Flow

  1. Run the app and open /input
  2. Type a name (e.g. Ahmad) and click Send
  3. Browser goes to /submit and shows Hello Ahmad

6. Network Tab Check

Inspect → Network → submit the form. The /submit entry should show Method POST, Status 200 OK, and response body Hello Ahmad.

Lesson Q&A

GET retrieves data from the server (e.g. loading /input). POST sends data to the server (e.g. submitting the form to /submit).

action sets the target URL; method="POST" sets the request type; name="username" is the key used on the server as request.form["username"].

Open Inspect → Network, submit the form, then open the /submit request. Confirm Method is POST, Status is 200 OK, and the Response tab shows the greeting text.
