1. Why Measure Error?

No model is perfect on unseen data. Claims of 100% accuracy are a red flag. Mean Squared Error (MSE) is the standard metric used to quantify prediction error, tune models, and set realistic client expectations.

2. Train vs Test

  • Training set: larger share used to fit the model
  • Test set: held out and never used during training

Evaluating on training data only measures memorization. Hidden test data checks true generalization.

3. Actual, Predicted, and Error

Error = Predicted − Actual

Overestimates give positive error; underestimates give negative error.

4. MSE Formula

MSE = (1/N) × Σ (Predictedᵢ − Actualᵢ)²

Steps: compute each raw error → square it → sum → divide by N. Squaring removes sign cancellation.

6. Why Square?

  • Removes negative signs so errors cannot cancel
  • Penalizes large mistakes more heavily (quadratic growth)
  • Produces a smooth, differentiable loss suited to optimizers like gradient descent

7. Client Communication

Report both performance and expected MSE so stakeholders understand operational bounds before deployment.
