1. Why Optimize?

A model starts with noticeable prediction error. Gradient Descent is the most common algorithm for iteratively reducing that cost toward a minimum.

Gradient = slope of changing values; Descent = moving downward. Together: step down the error slope to the lowest cost point.

2. Ball-on-a-Hill Analogy

Release a ball from a high point (high error). It rolls into the valley, may overshoot and oscillate, then settles at the bottom (minimum cost). Gradient Descent follows the same idea with parameter updates instead of gravity.

3. Update Steps

  1. Initialize parameters randomly (e.g. slope m and intercept b).
  2. Compute the gradient of the error at the current point.
  3. Update: m_new = m_old − (learning rate × gradient error)

4. Learning Rate (α)

A hyperparameter that sets step size. Typical values: 0.1, 0.05, 0.01. It scales how much of the gradient is applied each iteration so updates stay controlled.
