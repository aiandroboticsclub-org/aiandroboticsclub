1. Introduction: Why Do We Need File Handling?

In earlier programming lessons, all data used in programs was written directly inside the code itself. However, as programs scale and begin handling large volumes of information, it becomes impossible to keep all data embedded inside the code.

In real-world development and data-driven projects:

  • Large datasets are stored externally across different files.
  • Data received from clients or external sources arrives in the form of files rather than hardcoded variables.
  • File handling enables a Python program to open external files, read their contents, process the information, and write or update new data back into storage.

2. Common Data File Formats

External client data commonly arrives in several distinct formats:

  • Text files (.txt): Files containing simple, plain human-readable text data.
  • CSV files (.csv): Stands for Comma Separated Values, structured for tabular records.
  • JSON files (.json): Widely used in web applications and has become an established standard for sharing data across web protocols.

3. The File Handling Lifecycle

Interacting with a file in Python follows three mandatory stages:

  1. Open the file: Creates a file object and establishes a connection between Python and the disk file.
  2. Read or write data: Executes operations via file object methods.
  3. Close the file: Releases the file back to the operating system and saves changes safely.

4. Reading a Text File (Mode 'r')

To read an existing file, use Python's built-in open() function. The function takes two primary arguments:

  1. File name: The path or name of the target file (e.g., "demo.txt").
  2. File mode: The string 'r', indicating that the file is being opened strictly for reading.
# 1. Open the file in read mode and store the file object
file = open("demo.txt", "r")

# 2. Read the entire content of the file
content = file.read()

# 3. Print the extracted content
print(content)

# 4. Close the file after use
file.close()

Execution Walkthrough

  • When open("demo.txt", "r") executes, Python checks whether demo.txt exists in the current working directory.
    • If the file does not exist, Python throws an error at this stage.
    • If the file is found, Python opens it, wraps it in a file object, and assigns it to the file variable.
  • Calling file.read() extracts the stored text from the file. In our example file (demo.txt), the file contains two sentences: "This is a test" and "New line added".
  • Executing print(content) prints those two sentences to the console.
  • Finally, file.close() closes the file connection.

5. The Critical Importance of Closing Files

Opening a file leaves it in an active, open state inside your program.

  • Why closing is mandatory: Once you finish reading or writing, you must call file.close() so the file returns to a closed state on the hard disk.
  • Risks of omitting close(): If you fail to close the file, it remains open in memory. Once your program terminates, the file may become corrupted or damaged.
  • As a matter of good programming practice, always ensure every opened file is closed immediately after its operations are complete.

6. Writing to a Text File (Mode 'w')

To write data into a file, call open() with the mode argument set to 'w' instead of 'r'. This explicitly informs Python that the file is opened for writing.

# 1. Open the file in write mode
file = open("demo.txt", "w")

# 2. Write a new sentence into the file
file.write("This is another test")

# 3. Close the file as good programming practice
file.close()

Execution Walkthrough & Overwriting Behavior

  • When file.write("This is another test") executes under write mode ('w'), Python overwrites the entire file.
  • The previous contents (the two original sentences) are replaced by the single new sentence: "This is another test".
  • Inspecting demo.txt on the disk confirms that the old text is gone and the file now contains only the new string.
