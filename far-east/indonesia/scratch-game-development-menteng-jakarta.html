1. Handling Multiple Outcomes with elif

elif (else if) tests additional conditions only when the previous if was False.

2. Student Grading Example

score = 85

if score > 90:
    print("Grade: A+")
elif score > 80:
    print("Grade: A")
else:
    print("Try again")

With score 85, the first check fails and the elif succeeds → “Grade: A”.

3. Nested If Statements

age = int(input("Enter your age: "))

if age > 18:
    country = input("Enter your country: ")
    if country == "Pakistan":
        print("You can vote in Pakistan.")
    else:
        print("You cannot vote in Pakistan.")
else:
    print("You cannot vote.")

4. Combining Conditions with and

if age > 18 and country == "Pakistan":
    print("Eligible voter")
else:
    print("Not an eligible voter")

5. Case Sensitivity and .capitalize()

country = input("Enter your country: ").capitalize()
if age > 18 and country == "Pakistan":
    print("Eligible voter")

.capitalize() uppercases the first letter so “pakistan” becomes “Pakistan”.

Lesson Q&A

elif tests another condition only if the previous if was False, enabling multi-branch decisions without redundant upper-bound checks.

A nested if sits inside another if. Deep nesting hurts readability—flatten with the and operator when possible.

String comparisons are case-sensitive. .capitalize() standardizes the first letter so inputs like “pakistan” match “Pakistan”.
