1. Introduction: What Is a While Loop?

A while loop repeats a block as long as its condition is True. When the condition becomes False, the loop stops.

2. When to Use while vs for

Featurefor Loopwhile Loop
Iterations known?Yes (range, list, string)No—depends on a condition
Ideal useFixed sequencesInput validation, state checks

3. Counting with a While Loop

count = 1
while count <= 5:
    print(count)
    count = count + 1
print("Loop finished")

Prints 1–5, then exits when count becomes 6.

4. Avoiding Infinite Loops

Always update the condition variable inside the loop so the condition can become False. Otherwise the loop runs forever and may freeze the program.
