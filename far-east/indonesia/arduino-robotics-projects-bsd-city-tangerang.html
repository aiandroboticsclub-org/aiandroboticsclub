1. Recap: Variables as Labeled Containers

In Python, a variable functions as a storage box or container held in computer memory to store data, with a label placed on the box representing its variable name. The data held inside is called a “variable” because its value can vary or change throughout the life of a program.

In Python, you do not need to explicitly declare a data type beforehand. Whenever you assign data to a variable, Python automatically inspects the assigned value and determines its data type dynamically.

3. Detailed Breakdown & Code Examples

1. Integer (int)

  • Definition: Used to store whole numbers, including positive numbers, negative numbers, and zero, without any fractional or decimal component.
  • Examples: 2, 5, 7, -3, -5, -8.
# Creating an integer variable
age = 25

# Displaying the value
print(age)

Output:

25

2. Floating-Point Numbers (float)

  • Definition: Used for storing numbers that contain a fractional or decimal point.
  • Examples: 3.5, 7.9, -8.5.
  • Mathematical Operations: You can execute standard mathematical operations (+, -, *, /) directly on numerical variables.
score = 3.5
print(score)
print(score + 1)

3. Text Strings (str)

name = "Ali Zafar"
print(name)
message = name + " is good"
print(message)

4. Boolean Values (bool)

is_passed = True
print(is_passed)
is_passed = False
print(is_passed)

4. Checking Variable Types with the type() Function

score = 3.5
print(type(score))
