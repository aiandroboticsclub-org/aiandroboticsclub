1. What is a Variable? The Box Analogy

In Python and programming in general, a variable is one of the most fundamental concepts. A variable acts as a container or box used to store data in computer memory.

Imagine you want to store information about a student named Ali:

  • You can dedicate one box to hold Ali’s name.
  • A second box to hold Ali’s age.
  • A third box to hold his grade or academic GPA.
  • A fourth box to record his habits or other attributes.
name = "Ali"
age = 21
gpa = 3.4

In programming, these named storage boxes are called variables.

2. Why Are They Called “Variables”?

The word variable literally means something that is capable of changing. In programming, variables are given this name because the data stored inside them can be updated or replaced whenever needed:

  • If Ali is currently 21 years old, his age variable holds 21.
  • Next year, that value can be updated to 22.
  • If Ali is currently in Grade 12, the grade variable can later be modified to Grade 13.

Variables do not just hold data once; they allow programs to alter and update that data as execution progresses.

3. Dynamic Typing: How Python Creates Variables

In many traditional languages (such as C++ or Java), programmers must explicitly declare a variable and specify its data type (such as int, float, or long) before assigning a value to it.

Python simplifies this process entirely through dynamic typing:

  • No explicit declaration: You do not declare a data type beforehand.
  • Single-line execution: Simply write the variable name, followed by the assignment operator (=), followed by the value.

Writing a single assignment statement performs three actions simultaneously:

  1. Creates the variable in memory.
  2. Determines its data type automatically by examining the assigned data.
  3. Initializes it with the specified value.

Because Python is an interpreted language, variable types are resolved dynamically at runtime based on how they are used, rather than during a static compilation step.

4. Beginner Examples of Data Stored in Variables

1. Integers (Whole Numbers)

Used for numbers without fractional or decimal parts.

age = 21

Python inspects 21, automatically creates the variable age, and assigns it the integer data type.

2. Floating-Point Numbers (Decimals)

Used when numbers include decimal values.

gpa = 3.4

Python assigns this variable the float type to store decimal numbers accurately.

3. Text Strings

Used to store alphabetic characters, words, or full sentences.

message = "This is a very nice programming language"

Enclosing characters in quotes signals to Python that the variable holds a text string.

5. Best Practices: Writing Meaningful Variable Names

Beginners often name variables with arbitrary single letters such as a = 5, b = 10, or c. While Python executes this code without issue, it creates serious maintenance problems:

  • In large codebases, single letters give no indication of what the variable actually stores or why it was created.
  • If you or a teammate inspect the code months or years later, poor naming makes the logic difficult to decipher.

The Descriptive Naming Rule:

  • Always choose descriptive, intuitive names that clearly explain their purpose, typically longer than three characters.
  • Use student_name instead of a.
  • Use total_marks instead of x.

While descriptive names require slightly more typing, they drastically improve code readability and long-term maintainability.

6. Python Variable Naming Rules

When creating variable names in Python, you must follow specific language rules:

RuleExplanation & Valid PatternsInvalid Patterns
Allowed Characters Can contain letters, digits, and underscores (_). Special symbols like @, $, %, or - are not allowed.
Starting Character Must begin with a letter (lowercase or uppercase) or an underscore (_). Standard practice prefers starting with lowercase letters. Cannot begin with a digit (e.g., 1variable is invalid).
No Whitespace Spaces are not allowed inside variable names, as spaces cause Python to interpret words as separate tokens. student name = "Ali" triggers a syntax error.
No Reserved Keywords Python reserved keywords cannot be used as variable names. Words like for, while, if, or else cannot be variable names.

7. Common Naming Styles

When a variable name contains multiple words, developers use standardized formatting styles:

  • Snake Case (snake_case):
    • Words are written in lowercase and joined with underscores.
    • Examples: student_name, total_marks.
  • Camel Case (camelCase):
    • Words are joined without spaces or underscores; the first word begins with a lowercase letter, and each subsequent word starts with a capital letter.
    • Examples: studentName, totalMarks.

Lesson Q&A

A variable is a storage container or “box” in computer memory used to hold data (such as numbers or text). It is called a “variable” because the data stored inside it is capable of changing over time. For example, a student’s age variable can initially hold 21 and later be updated to 22 in subsequent years without needing to create an entirely new storage container.

Unlike languages that require you to explicitly declare a data type (like int or float) before using a variable, Python is dynamically typed. When you assign a value using the format variable_name = value, Python automatically executes three steps at once: it creates the variable, determines its data type based on the assigned data, and initializes it with that value at runtime.

When naming variables in Python, you must observe these key rules:

  • Starting Character: Must begin with an alphabetic letter or an underscore (_), and can never begin with a number.
  • No Spaces: Spaces are strictly disallowed between words.
  • No Reserved Keywords: Built-in keywords such as if, else, for, and while cannot be used as variable names.
  • Conventions: Names should be descriptive (e.g., student_name or total_marks) rather than single letters, formatted using styles like snake_case (with underscores) or camelCase (capitalizing subsequent words).
