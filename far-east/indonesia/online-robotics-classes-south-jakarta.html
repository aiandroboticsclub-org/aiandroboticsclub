1. Introduction to Operators

In Python, operators are special symbols and keywords applied to variables and values to carry out specific computational tasks.

  • Unary Operators: Require only a single operand.
  • Binary Operators: Require two operands.

Python operators are divided into four major functional groups: Mathematical (Arithmetic), Comparison, Logical (Boolean), and Compound Assignment operators.

Standard Division (/) vs. Floor Division (//)

  • Standard Division (/): Always produces a floating-point number (e.g., 15 / 3 outputs 5.0).
  • Floor Division (//): Rounds down to the nearest integer floor (e.g., 17 // 3 outputs 5).
print(17 // 3)  # 5
print(10 % 3)   # 1
print(2 ** 3)   # 8

5. Compound Assignment Operators

Compound assignment operators update a variable’s value in place:

x = 10
x += 5   # x = x + 5 → 15
x -= 3   # x = x - 3 → 12
x *= 2   # x = x * 2 → 24
x /= 4   # x = x / 4 → 6.0
print(x)

Lesson Q&A

  • Standard Division (/): Always returns a floating-point number (e.g., 15 / 3 → 5.0).
  • Floor Division (//): Returns an integer by discarding any fractional remainder (e.g., 17 // 3 → 5).

Comparison operators always return a Boolean (True or False).

  • == checks equality (5 == 5 → True).
  • != checks inequality (7 != 3 → True).

They perform arithmetic and update the variable in one step:

  • x += 5 is shorthand for x = x + 5
  • x -= 3 is shorthand for x = x - 3
  • x *= 2 is shorthand for x = x * 2
  • x /= 4 is shorthand for x = x / 4
