1. Introduction: Iterating Over Data Structures

In Python, loops do more than repeat instructions or count numbers. They can also travel through data structures such as strings and lists.

A string is an ordered sequence of characters. A for loop can visit each character, allowing you to inspect letters, search for patterns, count occurrences, and transform text.

Key idea: A string is iterable. This means Python can give you its characters one at a time inside a loop.

2. Example 1: Character-by-Character Iteration

Let's begin with the word Python. The loop assigns one character at a time to the variable char.

# Print each character of a string
for char in "Python":
    print(char)

3. Example 2: Counting Specific Character Occurrences

Suppose we want to find out how many times the letter a appears in banana. We can combine a for loop with an if statement.

Our plan

Step Instruction Purpose
1 count = 0 Start the counter at zero.
2 for char in "banana" Visit each character.
3 if char == "a" Check for the target letter.
4 count += 1 Add one when a match is found.
5 print(count) Display the final total.

Python code

# Start the counter
count = 0

# Visit every character in the string
for char in "banana":
    # Check whether the character is a
    if char == "a":
        count += 1

# Display the final count
print("Total occurrences of 'a':", count)

Remember: Python string indexes start at zero. The three occurrences of a are at indexes 1, 3, and 5. The final counter is 3.

4. Example 3: Reversing a String Using a Loop

We can also use a loop to create a new string in reverse order. The trick is to place each new character in front of the string we have already built.

# Original string
text = "Python"
reversed_text = ""

# Add each new character to the beginning
for char in text:
    reversed_text = char + reversed_text

# Display the reversed string
print("Reversed string:", reversed_text)

Why does this work? The expression char + reversed_text puts the latest character at the beginning. Repeating this process gradually builds the word backward.

Lesson Q&A

In Python, a text string acts as an iterable sequence of characters. When you run for char in "Python":, the loop steps through the string character-by-character from left to right, assigning each letter to the loop variable char in sequence. Because print() automatically inserts a newline after each call, each letter displays on a separate line.

You initialize a counter variable to zero (count = 0) before the loop begins. Then, you iterate through the string with a for loop, using an if statement inside the loop body to compare each character to the target character (e.g., if char == 'a':). Each time a match is found, you increment the counter by 1. Once the loop completes all iterations, the final count is displayed.

Loops can be used across data structures for multiple tasks:

  • Iterating & Printing: Stepping through characters sequentially for inspection or formatted display.
  • Searching & Counting: Scanning through text to find patterns or determine how frequently a character appears.
  • Manipulating Data: Restructuring the underlying sequence, such as reversing a word character-by-character.
