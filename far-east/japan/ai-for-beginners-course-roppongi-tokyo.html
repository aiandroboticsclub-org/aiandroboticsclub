1. Introduction: Iterating Over Data Structures

In Python, loops are not limited to repeating numbers or executing counters; they are frequently used to iterate across data structures such as strings and lists.

Because a text string is an ordered sequence of individual characters, a loop can step through each character one by one. By looping through strings, you can inspect individual letters, search for specific patterns, count character occurrences, and manipulate text data programmatically.

2. Example 1: Character-by-Character Iteration

The most direct way to loop through a string is using a for loop to access each character sequentially:

# Iterating through each character of a string
for char in "Python":
    print(char)

How It Works & Output

  • Python starts at the beginning of the string "Python" and assigns each letter to the loop variable char in sequence.
  • Because Python’s print() function defaults to placing each output call on a new line, each character appears on its own line:
P
y

h

3. Example 2: Counting Specific Character Occurrences

Rather than simply counting all characters in a string, you can combine a for loop with an if conditional statement to count how many times a specific character appears.

Task: Count How Many Times 'a' Appears in "banana"

To count occurrences:

  1. Initialize a counter variable (count = 0) before the loop begins.
  2. Loop through each character of the string "banana".
  3. For each iteration, check if the character matches 'a' using an if condition.
  4. If it matches, increment the counter by 1 (count = count + 1 or count += 1).
  5. After the loop finishes evaluating the entire string, print the counter value.
# 1. Initialize counter to zero
count = 0

# 2. Iterate through each character in the string "banana"
for char in "banana":
    # 3. Check if the current character is 'a'
    if char == "a":
        count += 1

# 4. Print the final count after exiting the loop
print("Total occurrences of 'a':", count)

Execution Result:

Total occurrences of 'a': 3

In the string "banana", the letter 'a' appears at index positions 1, 3, and 5 (three times total). The loop inspects every character, increments the counter on each match, and outputs 3.

4. Example 3: Reversing a String Using a Loop

Loops can also be used to manipulate and transform string data, such as reversing the sequence of characters in a word.

# Original string
text = "Python"
reversed_text = ""

# Prepending each character to reverse the string
for char in text:
    reversed_text = char + reversed_text

# Displaying the reversed output
print("Reversed string:", reversed_text)

How the String Reversal Works

  • By taking the current character char and placing it in front of the accumulated string (char + reversed_text), each incoming letter gets prepended:
    • Pass 1: 'P' + "" → 'P'
    • Pass 2: 'y' + 'P' → 'yP'
    • Pass 3: 't' + 'yP' → 'tyP'
    • Subsequent passes: builds up to 'nohtyP'.
  • When executed, Python prints the reversed string: Reversed string: nohtyP

5. Summary: Practical Takeaways

  • Sequence Traversal: Strings behave as iterable sequences, allowing standard for loops to process text character-by-character.
  • Conditional Filtering: Nesting an if condition inside a string loop enables targeted operations, such as tallying specific characters.
  • Data Manipulation: Iteration provides fine-grained control to restructure, inspect, and transform string contents.
