1. Introduction & Overview

Before writing artificial intelligence algorithms, you must configure a clean, functional programming environment. This lecture covers how to download Python from its official portal, understand Python version lifecycles, evaluate modern code editors, and set up an isolated workspace using the Anaconda Distribution and Jupyter Notebook.

2. Downloading Python from the Official Website

  • Official Source: Navigate in your web browser to python.org.
  • Operating System Support: The website automatically detects your operating system (such as Windows or macOS) and provides the corresponding installer. Installers are also available for Linux, Android, and other platforms.
  • Installer vs. Standalone: You can download through the automated Python Install Manager or download a direct standalone installer.
  • Version Compatibility in AI:
    • While the latest stable Python releases are available, several advanced AI libraries currently maintain verified compatibility up to recent 3.x releases such as Python 3.12.
    • Basic AI and general Python programming can run on the latest versions, but keeping compatibility in mind is critical when installing specialized data science and machine learning packages.

3. Python’s Version Lifecycle: From Python 2 to Python 3

Version / MilestoneNotes
Python 1.xInitial release
Python 2.xMassive global adoption in production
Python 3.xArchitectural revamp & modernized core
2020 MilestonePython 2.7 reached End-of-Life (EOL)
  • The Python 2 vs. 3 Dilemma: In the past, vast amounts of enterprise software were deployed in Python 2. Because Python 3 brought fundamental language changes, developers previously faced a dilemma: choose Python 3 for modern libraries, or stay on Python 2 for mature community packages.
  • The 2020 Transition: In 2020, Python 2.7 reached official End of Life (EOL).
  • Understanding End of Life (EOL): When a Python version reaches EOL, the core development team no longer issues updates. If security vulnerabilities or broken dependencies arise, they are not patched, making running EOL versions a security risk.
  • Release Cycles: Active versions receive both feature updates and security maintenance during their primary support window before transitioning to security-only fixes and eventual retirement.

5. Why Use Anaconda Distribution?

  • Contained Virtual Environments: Anaconda provides an isolated environment container. Any libraries or Python versions installed within this container do not interfere with other Python installations or operating system dependencies.
  • 8,000+ Pre-Installed Libraries: The complete Anaconda package bundles over 8,000 libraries, saving you from having to manually download data science packages individually.
  • Built-in Tools: Comes integrated with Jupyter Notebook, JupyterLab, and Spyder IDE.

6. Step-by-Step Installation & Setup Guide

Step 1: Download Anaconda

  1. Search for “Anaconda Distribution” and navigate to the official download page.
  2. Download the Windows 64-bit Graphical Installer (the file is approximately 1.1 GB).

Step 2: Run the Installer

  1. Open the downloaded installer file.
  2. Click Next and accept the license terms (I Agree).
  3. For installation type, select “Just Me (recommended)” so the setup remains scoped to your user account without altering other system profiles.
  4. Verify destination folder and disk space: Anaconda requires about 6.1 GB of free disk space (ensure extra storage is available for your program files and datasets).
  5. Proceed through the wizard to complete the installation.

Step 3: Launching Jupyter Notebook

There are two ways to start Jupyter Notebook:

  • Method 1 (Via Anaconda Navigator):
    1. Open your Windows Start Menu and search for Anaconda Navigator.
    2. Launch the application (it takes a few moments to initialize configurations depending on your system’s processing speed).
    3. From the dashboard, locate Jupyter Notebook and click Launch. It will open your home directory directly inside your default web browser.
  • Method 2 (Direct Launch):
    1. Open the Windows Start Menu and search directly for Jupyter Notebook.
    2. Click the icon to open a command prompt console that automatically starts the local server and opens Jupyter Notebook in your web browser.

Lesson Q&A

Jupyter Notebook is preferred because of its interactive, cell-based architecture. Instead of having to execute an entire script from start to finish every time, Jupyter allows developers to run code cell-by-cell or line-by-line and view the output, tables, and visualizations immediately underneath. This makes it ideal for step-by-step data analysis, visual inspection, and iterative machine learning experimentation.

Anaconda is a specialized distribution designed for scientific computing and data science:

  • Environment Isolation: It creates a contained environment so that packages installed for your projects do not conflict with or disrupt other Python versions or operating system setups on your computer.
  • Massive Built-in Ecosystem: The distribution bundles over 8,000 pre-configured libraries alongside built-in coding tools like Jupyter Notebook, JupyterLab, and Spyder, eliminating the need to configure complex dependencies manually.

You can launch Jupyter Notebook using either of the following methods:

  1. Via Anaconda Navigator: Open the Start Menu, launch the Anaconda Navigator desktop dashboard, find the Jupyter Notebook tile, and click Launch.
  2. Direct Windows Search: Type Jupyter Notebook directly into the Windows search bar and run the application. This launches a background command prompt that automatically opens the Jupyter file browser inside your web browser.
