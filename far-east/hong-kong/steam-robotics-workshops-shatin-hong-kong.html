1. Introduction: Python’s Syntax Simplicity

When comparing Python to traditional programming languages, the most striking difference is its clean and straightforward syntax. Older languages like C++ and Java enforce strict rules, such as requiring every single statement to terminate with a semicolon (;). Missing a semicolon in those languages triggers syntax errors that beginners often spend significant time troubleshooting.

In Python, such unnecessary restrictions have been removed:

  • No semicolons are required at the end of lines.
  • No boilerplate wrapper code (such as class definitions or main methods) is needed just to print a simple message.
  • You write precisely the command you want executed, and Python runs it directly.

2. Jupyter Notebook Interface & File Formats

Jupyter Notebook does not use a standalone desktop IDE; instead, it hosts an interactive code editor directly inside your web browser.

ExtensionCharacteristics
.ipynb (Jupyter Notebook) Interactive, segmented code and text cells; executes cell-by-cell with instant inline output; ideal for experimentation, learning, and debugging.
.py (Standard Python Script) Entire codebase executes together from top to bottom; run in editors like VS Code or PyCharm; standard for production server deployments.

Understanding .ipynb vs. .py Files

  • .ipynb (Interactive Python Notebook):
    • Code is organized into modular code cells interspersed with text segments.
    • Cells can be executed individually, showing output directly below each cell.
    • If an output needs adjustment, you can edit that specific cell and re-run it without re-executing the rest of the script.
    • Ideal for exploratory programming, data science, and step-by-step experimentation.
  • .py (Standard Python Script):
    • The entire program exists in a single continuous script, executing as one whole unit from top to bottom.
    • Used primarily when code is finalized and ready for server deployment.
  • Debugging: Debugging is the process of identifying, inspecting, and fixing errors that occur in code. Because debugging is completed locally on your development machine, clean .py files perform better when deployed to servers.

3. Writing Your First Python Program: The print() Command

The Function and Structure of print()

In Python, output is displayed to the screen using the print() command. In programming terminology, “printing” refers to screen output and visual display, rather than sending text to a physical paper printer.

print("Hello Mr. Waqas")
  1. The Command Name: print instructs Python to display output.
  2. Parentheses (): The brackets tell Python what specific content you want to display.
  3. Double Quotes "": Enclosing text inside quotation marks informs Python that the content is an English sentence (text/string) rather than numbers or variable names. Python outputs the enclosed text exactly as written.

4. Running and Editing Code Cells

  • Executing Code:
    • You can run a cell by clicking the Play button on the toolbar.
    • Alternatively, use the keyboard shortcut Shift + Enter.
  • Interactive Output: When executed, Python displays the output immediately below the cell and automatically advances focus to the next cell.
  • Editing and Adding Multiple Statements: In Jupyter Notebook, you can modify an existing cell at any time and re-run it. To display multiple lines, write separate print() commands on separate lines without semicolons or separator symbols:
print("Hello Mr. Waqas")
print("Welcome")

Output:

Hello Mr. Waqas
Welcome

Both sentences display sequentially on the screen. No extra header declarations or environment setup lines are required.
