1. What Flask Is

Notebooks and local scripts cannot serve clients by themselves. Flask is a lightweight Python web framework that turns models and pipelines into websites or APIs that browsers and apps can call.

2. Core Capabilities

  • Minimalist core — flexible, low boilerplate
  • Built-in server & debugger — fast local testing
  • Jinja2 — dynamic HTML templates
  • URL routing — map paths to Python functions
  • REST endpoints — expose predictions over HTTP

3. Serving an ML Model

Typical flow: client sends features → Flask parses the request → loaded model runs inference → Flask returns JSON or HTML.

from flask import Flask, request, jsonify
import numpy as np

app = Flask(__name__)

class DummyModel:
    def predict(self, features):
        return [int(np.sum(features) > 50)]

model = DummyModel()

@app.route("/predict", methods=["POST"])
def predict():
    data = request.get_json()
    features = data.get("features", [])
    prediction = model.predict(features)
    return jsonify({"status": "success", "prediction": prediction})

if __name__ == "__main__":
    app.run(debug=True)

Lesson Q&A

Flask is a lightweight Python web framework for apps and APIs. It is minimal, flexible, ships with a dev server and debugger, and plugs cleanly into Scikit-Learn, PyTorch, and TensorFlow for rapid ML prototyping.

Client sends input → Flask parses features → model runs inference → Flask returns the prediction (often via jsonify) as HTML or JSON.

Flask is minimal and very flexible with a gentle learning curve—ideal for APIs and ML demos. Django is fuller and more opinionated for large apps. FastAPI is async and high-speed for performance-focused APIs.
