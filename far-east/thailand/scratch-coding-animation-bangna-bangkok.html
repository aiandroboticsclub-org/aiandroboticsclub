1. Routes and Views

A route is the URL path (/, /about, /contact). A view is the Python function that runs when that path is requested. @app.route() connects the two.

2. Multi-Route App

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Welcome to the Flask App"

@app.route("/about")
def about():
    return "This is a simple route example to the about page"

@app.route("/contact")
def contact():
    return """
    
Contact Us

    
You can reach our organization at: info@dgskills.pk

    """

if __name__ == "__main__":
    app.run(debug=True)
