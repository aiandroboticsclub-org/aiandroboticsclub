1. Manual Code vs Scikit-Learn

Building linear regression by hand teaches derivatives, learning rates, and updates for m and b. In production, engineers use libraries such as Scikit-Learn so training and prediction take only a few clear lines.

2. Setup

Install with pip install scikit-learn. Import:

  • from sklearn.linear_model import LinearRegression
  • NumPy for arrays; Matplotlib if you plot

3. Data and Scatter View

Define feature matrix X (2D) and target vector y. A scatter plot often shows a linear trend; no single line hits every point. The goal is the line of best fit that minimizes overall squared error.

4. Fit and Predict

  1. model = LinearRegression()
  2. model.fit(X, y) — runs optimization (e.g. OLS / gradient-style updates) under the hood
  3. y_pred = model.predict(X)

.fit() finds optimal slope and intercept without hand-written epoch loops.

5. Learned Parameters

  • model.coef_ → slope m (example: 1.40)
  • model.intercept_ → intercept b (example: 1.40)

Equation form: ŷ = 1.40x + 1.40. Example predictions: [2.8, 5.6, 7.0, 8.4, 11.2].
