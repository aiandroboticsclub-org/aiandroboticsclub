Chapter 131 – K-Means with Scikit-Learn (Part 1)

1. Unsupervised Setup on Iris

Iris has 150 samples and 4 features (sepal/petal length and width), plus class labels for supervised tasks. For K-Means we drop the labels and pass only the feature matrix X = iris.data so the algorithm discovers groups without targets.

2. Centroid Initialization

Pure random starts can place two centroids in the same natural cluster, so one real group is split and another is left uncovered. Two safeguards help:

  • init='k-means++' — samples starts far apart using distance-based probabilities.
  • n_init=10 — runs 10 seeds and keeps the lowest-inertia solution.

4. Code Sketch

from sklearn.datasets import load_iris
from sklearn.cluster import KMeans

iris = load_iris()
X = iris.data  # (150, 4) — labels discarded
print("Feature matrix:", X.shape)

kmeans = KMeans(
    n_clusters=3,
    init="k-means++",
    n_init=10,
    max_iter=300,
    random_state=42,
)
kmeans.fit(X)

print("Centroids shape:", kmeans.cluster_centers_.shape)  # (3, 4)
print("Centroids:\n", kmeans.cluster_centers_)
print("First 10 labels:", kmeans.labels_[:10])

5. What the Fit Returns

  • cluster_centers_ — 3×4 matrix of centroid coordinates in feature space.
  • labels_ — length-150 array of cluster ids (0, 1, or 2) per sample.

Example: early Iris rows often land in the same cluster (e.g. Cluster 0), matching the tight Setosa-like group in feature space.

Lesson Q&A

K-Means is unsupervised, so it must not see targets. Use only X = iris.data with shape (150, 4).

Random starts can put two centroids in one true cluster. k-means++ spreads starts by distance; n_init=10 tries several seeds and keeps the lowest inertia.

cluster_centers_ is a 3×4 matrix of centroid coordinates; labels_ is 150 integers (0–2) assigning each sample to a cluster.
