Chapter 129 – Choosing K in K-Means

1. Why K Is Hard

Unlike supervised models, clustering has no labels to tell you how many groups exist. Common ways to pick K are domain knowledge, the elbow method (WCSS), and the silhouette score—often used together.

2. Three Methods

Domain knowledge: Ask stakeholders how many operational groups make sense (e.g. customer tiers). Strongest when business logic is clear.

Elbow method: Plot within-cluster sum of squares (WCSS / inertia) vs K. WCSS falls as K grows; the “elbow” is where the curve bends and further K adds little compression. Stopping near the elbow avoids over-splitting natural groups.

Silhouette score: Scores each point from −1 to +1 by how close it is to its own cluster versus others. Average silhouette near +1 is better; 0 is boundary-like; −1 suggests wrong assignment. Prefer the K with the highest average score.

3. Python Sketch

from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

X, _ = make_blobs(n_samples=300, centers=4, cluster_std=1.0, random_state=42)
k_range = range(2, 15)
wcss, sil = [], []
for k in k_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X)
    wcss.append(km.inertia_)
    sil.append(silhouette_score(X, labels))

best_k = list(k_range)[sil.index(max(sil))]
print("Best K by silhouette:", best_k)

plt.subplot(1, 2, 1); plt.plot(k_range, wcss, "bo-"); plt.title("Elbow (WCSS)")
plt.subplot(1, 2, 2); plt.plot(k_range, sil, "ro-"); plt.title("Silhouette")
plt.tight_layout(); plt.show()

4. Demo Outcome

On synthetic blobs with 4 true centers, both elbow and silhouette typically agree on K = 4 (silhouette peaks near ~0.65–0.80; WCSS flattens after K=4).

Sensors, decisions and motion in plain language

A sensor is a way for a machine to measure something in the physical world—distance, light level or a simple switch state. The measurement becomes a number the program can compare. A decision is a rule: if the number is smaller than a limit, change behaviour. Motion is what motors or simulated actuators do when the program sends a command. Online robotics classes for kids in Paris spend real time making that chain visible so students do not treat robots as black boxes.

Beginners often overcomplicate the first project. Mentors keep the first goals small: stop before a virtual wall, blink a pattern, turn when a condition is true. Each success is narrated by the student. Narration is assessment. If the story of the program is clear, the logic is usually clear too.
