Prototyping Circuit Logic: Bridging Software Code and Microcontrollers for Nantes Youth

Arduino sits at the meeting point of code and electrons. Arduino programming classes for kids in Nantes teach that meeting carefully: a sketch is a list of instructions; pins are doorways; sensors and LEDs are the world outside.

Beginners start with simple outputs—patterns of light—before sensors and motion. Each change is intentional. setup prepares the board; loop repeats behaviour. Students learn to point to each section and explain its job. Comments are written in plain language.

Safety is explicit. Low-voltage practices, supervised sessions, no unsupervised soldering narratives. If a family is not ready for hardware, simulators still teach the logic of setup and loop. We do not claim industrial robotics training on a first course page.
