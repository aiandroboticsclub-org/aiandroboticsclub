Visual coding is not a toy version of computer science—it is a front door. Scratch coding classes for kids in Toulouse emphasise events: when the green flag is clicked, when a key is pressed, when two sprites touch. Those events map cleanly onto later text languages.

A maze teaches boundaries; an animation teaches sequencing; a quiz teaches variables. The learning is in the redesign after the first version fails.
