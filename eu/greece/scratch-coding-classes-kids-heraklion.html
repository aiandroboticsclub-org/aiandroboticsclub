Chapter 138 – Principal Component Analysis (PCA) Explained

1. What Is PCA?

Principal Component Analysis reduces the number of features while keeping as much data variance as possible. High-dimensional data (e.g. 30 correlated columns) is mapped onto fewer orthogonal axes (principal components) sorted by variance.

2. Four Practical Benefits

  • Less overfitting: models learn broad patterns instead of noise
  • Faster training & inference: fewer features mean quicker compute
  • Noise filtering: low-variance directions are dropped
  • Visualization: 10+ dimensions become 2D or 3D plots

3. How Components Are Built

  1. PC1 — direction of maximum variance
  2. PC2 — next highest variance, orthogonal to PC1
  3. Remaining PCs sorted by decreasing variance
  4. Keep the top n components (user choice); discard the rest

4. Correlated Features Example

Math and Physics scores often move together. PCA can fold that shared trend into a single component, removing redundancy while retaining the spread of ability across students.

Lesson Q&A

PCA is a variance-preserving dimensionality reduction method. It keeps the directions that explain the most spread in the data, so models still see the important structure while training on fewer columns—often with better generalization and speed.

PC1 aligns with maximum variance; PC2 is orthogonal and captures the next most variance. Strongly correlated inputs (e.g. Math and Physics scores) are typically combined into shared components, cutting redundancy.

Pros: speed, noise reduction, visualization of high-D data. Cons: harder interpretability, some information loss, and a strict need to scale features before running PCA.
