Chapter 157 — Build a Basic Recurrent Neural Network Step by Step

1. Introduction & Environment Setup in Google Colab

Recurrent Neural Networks (RNNs) are specialized deep learning models built specifically to process sequential data step by step. Unlike feedforward architectures, RNNs maintain an internal hidden state that captures past information by incorporating feedback from previous time steps. This makes RNNs ideal for tasks such as text classification and time-series prediction.

To build and train an RNN efficiently, we use Google Colab, a free cloud-based platform that provides access to GPU hardware accelerators.

7. Complete Executable Python Code

Below is the complete, end-to-end Python script executed in Google Colab:

# =====================================================================
# Complete Basic RNN Script using TensorFlow & Keras (Topic 157)
# =====================================================================

import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense
import pandas as pd
import numpy as np

# 1. Load Dataset from CSV File
df_loaded = pd.read_csv('module_157_data.csv')

# 2. Separate Features (X) and Target Labels (y)
X = df_loaded.drop(columns=['target'], axis=1).values
y = df_loaded['target'].values

# 3. Reshape 2D Data (2000, 10) into 3D Tensor (2000, 10, 1) for Keras RNN
X = X.reshape((X.shape[0], X.shape[1], 1))
print(f"Reshaped Input Tensor Shape: {X.shape}")  # (2000, 10, 1)

# 4. Construct RNN Architecture using Sequential API
model = Sequential([
    SimpleRNN(32, input_shape=(10, 1)),
    Dense(1, activation='sigmoid')
])

# 5. Display Model Summary & Parameter Breakdown (1,121 Parameters)
model.summary()

# 6. Compile Model Hyperparameters
model.compile(
    optimizer='adam',
    loss='binary_crossentropy',
    metrics=['accuracy']
)

# 7. Train RNN Model for 20 Epochs
history = model.fit(
    X, y,
    epochs=20,
    batch_size=32,
    validation_split=0.2
)

# 8. Evaluate Final Model Performance
loss, accuracy = model.evaluate(X, y, verbose=0)
print(f"\n--- Final Model Evaluation ---")
print(f"Final Test Accuracy: {accuracy * 100:.2f}%")  # Output: 94.90%

Reshaping Code & Dimensions: The original dataset shape of (2000, 10) is converted to a 3D array of (2000, 10, 1) using the transformation X = X.reshape((X.shape[0], X.shape[1], 1)). This adds an explicit feature dimension of size 1 across the 10 time steps.

Sequential Model Initialization: The model is built using Keras's Sequential API (tf.keras.models.Sequential).

Layer 1: Recurrent Feature Extractor (SimpleRNN): A SimpleRNN layer with 32 units/neurons and an input_shape of (10, 1) extracts temporal features from the sequential steps. As a recurrent layer, it maintains a hidden state and combines previous step outputs with current inputs. This layer produces an output shape of (None, 32) and contains 1,088 trainable parameters.

Layer 2: Classification Output (Dense): A fully connected Dense layer with 1 node and a Sigmoid activation function serves as the binary classifier, outputting a probability corresponding to a "yes/no" class prediction. This layer contains 33 trainable parameters.

Total Parameters: The network contains 1,121 total parameters, all of which are trainable (0 non-trainable parameters), taking up approximately 4.38 KB of memory.

Compilation Hyperparameters: The model is configured via model.compile() using:

  • Loss Function: Binary Cross-Entropy (binary_crossentropy), which is specifically designed for binary classification tasks.
