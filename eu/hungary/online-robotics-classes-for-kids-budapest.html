Chapter 141 — PCA with Scikit-Learn — Part 1: Reduce the Number of Features

1. Introduction & End-to-End Workflow Overview

In machine learning, high-dimensional datasets containing dozens or hundreds of features present significant challenges. Working directly with high-dimensional data increases the risk of overfitting (where models memorize training noise) and degrades inference speed.

Principal Component Analysis (PCA) is an unsupervised learning algorithm that resolves high dimensionality by projecting features onto a smaller set of orthogonal principal components.

Core Mathematical Mechanics:

  • Eigenvectors: Define the directional axes of the data projection.
  • Eigenvalues: Quantify the amount of data variance preserved along each eigenvector axis.
  • Component Selection Trade-Off:
    • Selecting Fewer Components: Yields faster computation speeds but results in higher information loss.
    • Selecting More Components: Preserves more information and variance, but increases computational load.

2. Dataset Ingestion & Feature Standardization (StandardScaler)

For this implementation, we utilize Scikit-Learn's Breast Cancer Wisconsin Dataset (load_breast_cancer):

  • Dataset Shape: Contains 569 sample instances across 30 continuous physical features.
  • High-Dimensional Candidate: Having 30 continuous features makes this dataset an ideal candidate for dimensionality reduction.
import pandas as pd
from sklearn.datasets import load_breast_cancer
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# 1. Load Breast Cancer dataset and extract input features X
cancer = load_breast_cancer()
X = cancer.data
y = cancer.target

print(f"Original Dataset Shape: {X.shape}")  # Output: (569, 30)

Why Feature Standardization is Critical:

PCA is highly sensitive to unstandardized feature scales. When features exist on different numerical scales, features with larger raw magnitudes artificially dominate spatial direction calculations.

Applying StandardScaler().fit_transform(X) normalizes all 30 features to be centered around a mean of 0, ensuring equal feature weighting prior to PCA projection.

# 2. Standardize features using StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

3. Drastic Dimensionality Reduction (PCA(n_components=2))

We instantiate Scikit-Learn's PCA class, setting n_components=2 to compress the 30 input features down to 2 principal components (PC1 and PC2):

# 3. Instantiate PCA with 2 target components and fit_transform scaled data
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

# 4. Compare feature matrix shape before and after PCA
print(f"Shape Before PCA : {X_scaled.shape}")  # Output: (569, 30)
print(f"Shape After PCA  : {X_pca.shape}")     # Output: (569, 2)

By compressing 30 features into PC1 and PC2, the data representation drops from 30 columns to just 2 columns. Because PC1 and PC2 are orthogonal, they capture entirely independent data patterns.

4. Evaluating Explained Variance Ratio & Information Loss

To evaluate how much underlying information was retained after compressing 30 features into 2 components, we examine the Explained Variance Ratio (explained_variance_ratio_):

# 5. Extract explained variance ratios
variance_ratios = pca.explained_variance_ratio_
pc1_var = variance_ratios[0]
pc2_var = variance_ratios[1]

# 6. Sum individual ratios to calculate total preserved variance
total_preserved_var = pc1_var + pc2_var

print("--- Explained Variance Ratio Diagnostics ---")
print(f"PC1 Variance Contribution : {pc1_var * 100:.2f}%")    # 44.20%
print(f"PC2 Variance Contribution : {pc2_var * 100:.2f}%")    # 18.90%
print(f"Total Preserved Variance  : {total_preserved_var * 100:.2f}%")  # 63.24%

Analytical Variance Diagnostics:

  1. Component Contributions: PC1 accounts for 44.2% (0.442) of the total variance, while PC2 accounts for 18.9% (0.189).
  2. Total Preserved Variance (63.24%): Summing PC1 and PC2 yields 63.24% (0.6324) total preserved variance.
  3. Handling Client Requirements: Whether 63.24% variance coverage is sufficient depends on project and client requirements. If higher coverage is required, data scientists can increase the number of principal components (e.g., selecting 4 or 5 components) to reduce information loss.

6. Complete Executable Python Script

Below is the complete, runnable Python code implementing the end-to-end PCA workflow:

# =====================================================================
# Complete PCA Implementation Script (Topic 141)
# =====================================================================

import numpy as np
import pandas as pd
from sklearn.datasets import load_breast_cancer
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# 1. Load Dataset
cancer = load_breast_cancer()
X = cancer.data
y = cancer.target

# 2. Standardize Features
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. Apply PCA (30 features -> 2 components)
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

# 4. Print Shapes
print(f"Shape Before PCA : {X_scaled.shape}")  # (569, 30)
print(f"Shape After PCA  : {X_pca.shape}")     # (569, 2)

# 5. Evaluate Explained Variance Ratios
ratios = pca.explained_variance_ratio_
print(f"PC1 Variance Ratio: {ratios[0]:.4f}")  # 0.4427
print(f"PC2 Variance Ratio: {ratios[1]:.4f}")  # 0.1897
print(f"Total Preserved   : {np.sum(ratios):.4f}")  # 0.6324 (63.24%)

# 6. Plot Results
plt.figure(figsize=(8, 5))
plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap='plasma',
            alpha=0.8, edgecolors='k')
plt.xlabel('PC1')
plt.ylabel('PC2')
plt.title('PCA Reduction (569x30 -> 569x2)')
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()

Lesson Q&A

Feature standardization using StandardScaler is mandatory because PCA is highly sensitive to differences in unstandardized feature scales.

In the raw Breast Cancer dataset (which contains 30 continuous features), features exist on varying numerical ranges. If unscaled, features with larger raw magnitudes would artificially overpower direction calculations when extracting eigenvectors. Applying StandardScaler().fit_transform(X) normalizes all 30 features to be centered around a mean of 0, ensuring that every variable contributes equally during PCA dimensionality reduction.

Applying PCA(n_components=2) on the standardized Breast Cancer dataset produced the following results:

  • Shape Transformation: Transformed the feature matrix from 569 samples × 30 original features down to 569 samples × 2 principal components (PC1 and PC2).
  • Explained Variance Ratios:
    • Principal Component 1 (PC1): Captured 44.20% (0.442) of the total variance.
    • Principal Component 2 (PC2): Captured 18.90% (0.189) of the total variance.
    • Total Preserved Variance: Summing PC1 and PC2 yielded 63.24% (0.6324) preserved variance.

Adjusting Preserved Variance: If a client requires higher variance coverage (e.g., 85%+), the data scientist should increase the number of principal components (e.g., setting n_components=4 or 5). Retaining additional principal components preserves more data variance and reduces information loss.

Explainable AI (XAI) Limitation: PCA does not belong to Explainable AI because principal components are synthetic linear combinations of multiple original features. Because features are blended together into composite axes, it is difficult to interpret the direct physical meaning of transformed components.
