Computer Vision vs. Tabular Data Context:

  • Computer Vision: Image and video datasets naturally carry massive dimensionality because every single pixel location acts as an input feature column. Managing high dimensionality is a constant operational requirement in image processing.
  • Data Science / Tabular Data: Tabular client data usually contains fewer columns, but when dealing with high-dimensional plants or enterprise datasets, PCA is equally effective at compressing features.

2. Dataset Ingestion & Exploratory Data Analysis

For this project, we ingest Scikit-Learn's Digits Dataset (load_digits from sklearn.datasets):

  • Dataset Size & Shape: Contains 1,797 image samples across 64 continuous pixel features (representing an 8 × 8 grid of pixel values per image).
  • Target Classes: Contains 10 target classes representing handwritten digits from 0 through 9.
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 1. Load the Digits dataset
digits = load_digits()

# 2. Extract input feature matrix X (pixel grid) and target labels y
X = digits.data
y = digits.target

print(f"Dataset Shape: {X.shape}")  # Output: (1797, 64)
print(f"Number of Unique Digit Classes: {len(np.unique(y))}")  # Output: 10

3. Feature Standardization (StandardScaler)

Because PCA computes spatial variance directions across features, input pixel values must be standardized prior to projection. Applying StandardScaler().fit_transform(X) centers pixel features around a mean of 0.

# 3. Standardize raw pixel feature values
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

4. Extreme Dimensionality Reduction (PCA(n_components=2))

To visualize high-dimensional image data on a 2D scatter plot, we instantiate Scikit-Learn's PCA model with n_components=2, compressing the 64 pixel features down to 2 orthogonal principal components:

# 4. Instantiate PCA and transform standardized image features
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

# 5. Verify shape transformation
print(f"Original Feature Shape : {X_scaled.shape}")  # Output: (1797, 64)
print(f"Transformed PCA Shape  : {X_pca.shape}")     # Output: (1797, 2)

5. Quantitative Variance & High Information Loss Diagnostics

To evaluate how much original image information was preserved after compressing 64 pixels down to 2 components, we extract the Explained Variance Ratio (explained_variance_ratio_):

# 6. Extract individual and total explained variance ratios
ratios = pca.explained_variance_ratio_
pc1_var = ratios[0]
pc2_var = ratios[1]
total_preserved_var = np.sum(ratios)

print("--- Explained Variance Ratio Diagnostics ---")
print(f"PC1 Variance Contribution : {pc1_var * 100:.2f}%")    # 12.00%
print(f"PC2 Variance Contribution : {pc2_var * 100:.2f}%")    # 9.56%
print(f"Total Preserved Variance  : {total_preserved_var * 100:.2f}%")  # 21.59%

Analytical Variance Highlights:

  1. Low Individual Contributions: PC1 captures 12.0% (0.12) of total data variance, and PC2 captures 9.56% (0.0956).
  2. Total Preserved Variance (21.59%): Summing PC1 and PC2 yields a total preserved variance of 21.59% (0.2159).
  3. Purpose of Extreme Reduction: While retaining only 21.59% variance incurs high information loss, reducing data to 2 components serves an exploratory purpose: allowing data scientists to plot 2D graphs and gain visual insights into client datasets.

7. Optimal Component Selection: Grid Search & The Elbow Plot Strategy

To move beyond 2D visual exploration and identify the optimal number of components for production models, we use a Grid Search and Elbow Plot strategy:

  ┌─────────────────────────────────────────────────────────────┐
  │           Grid Search & Elbow Plot Optimization             │
  ├─────────────────────────────────────────────────────────────┤
  │  1. Loop across a candidate range of component counts       │
  │     (e.g., n_components from 2 to 40).                      │
  │                                                             │
  │  2. Compute total preserved variance for each count.        │
  │                                                             │
  │  3. Plot Component Count vs. Preserved Variance (Elbow Plot)│
  │     to identify the "elbow point" (inflection point).       │
  │                                                             │
  │  4. Select the optimal K value at the elbow point.          │
  └─────────────────────────────────────────────────────────────┘

By iterating through component counts in a loop, plotting preserved variance produces an Elbow Plot. The inflection point (elbow) reveals the optimal number of principal components needed to maximize variance preservation while discarding redundant pixel features.

Lesson Q&A

Dataset & Dimensions: Topic 142 utilized Scikit-Learn's Digits Dataset (load_digits), containing 1,797 image samples across 64 continuous pixel features (representing an 8 × 8 pixel grid per image) and 10 digit target classes (0 through 9). Its original matrix shape was (1797, 64).

Importance in Computer Vision: In computer vision, image and video datasets carry high dimensionality because every individual pixel location acts as an input feature column. High dimensionality creates computational bottlenecks, making PCA an essential tool for compressing pixel features before passing data to downstream machine learning algorithms.

Applying PCA(n_components=2) on the standardized Digits dataset yielded the following variance results:

  • PC1 Explained Variance: 12.00% (0.12).
  • PC2 Explained Variance: 9.56% (0.0956).
  • Total Preserved Variance: 21.59% (0.2159).

Why Preserved Variance Was Low: The total preserved variance (21.59%) was relatively low because compressing 64 continuous features down to just 2 components represents an extreme reduction (dropping over 78% of data variance). However, this 2-component reduction was performed intentionally to project high-dimensional image data onto a 2D scatter plot for visual exploration.

To find the optimal number of principal components beyond 2D visualization:

  1. Grid Search Loop: Execute a loop across a candidate range of component counts (e.g., testing n_components from 2 up to 40).
  2. Calculate Preserved Variance: Compute the total preserved variance ratio for each component count in the loop.
  3. Plot the Elbow Curve: Plot the candidate component counts on the X-axis against total preserved variance on the Y-axis to create an Elbow Plot.
  4. Identify the Elbow Point: Locate the inflection point (elbow) on the curve where adding more components yields minimal additional variance coverage. Selecting the K value at this elbow point establishes the optimal number of principal components.
