Chapter 151 — Neural Network Simulation: Understand How a Network Learns

1. Introduction & The Purpose of Interactive Neural Network Simulators

While the mathematical equations governing neural networks—such as weighted sums, activation functions, loss calculations, and backpropagation derivatives—are straightforward on paper, observing how these components interact in real-time can be challenging.

Interactive web-based neural network simulators solve this by providing a visual, hands-on environment. They allow students and AI engineers to inspect the inner mechanics of an Artificial Neural Network (ANN) step-by-step as it processes data, computes errors, updates connection weights, and shapes decision boundaries.

2. The Non-Linear XOR Problem & Simulator Architecture

To demonstrate how a neural network learns, simulators often use the classic XOR (Exclusive OR) logic problem.

  ┌─────────────────────────────────────────────────────────────┐
  │                  The XOR Truth Table & Non-Linearity        │
  ├──────────────────────────┬──────────────────────────────────┤
  │ Input Features (x1, x2)  │ Target Output (y)                │
  ├──────────────────────────┼──────────────────────────────────┤
  │    x1 = 0, x2 = 0        │          y = 0                   │
  │    x1 = 1, x2 = 0        │          y = 1                   │
  │    x1 = 0, x2 = 1        │          y = 1                   │
  │    x1 = 1, x2 = 1        │          y = 0                   │
  └──────────────────────────┴──────────────────────────────────┘

Why XOR Requires a Neural Network:

  • Non-Linear Separability: The XOR function outputs 1 if exactly one input is 1, and 0 if both inputs are identical (0 or 1). On a 2D graph, no single straight line can separate the 0 outputs from the 1 outputs.
  • Failure of Linear Models: Simple linear classifiers (like single perceptrons without hidden layers) cannot solve XOR.
  • Neural Network Solution: A Multi-Layer Perceptron (MLP) containing at least one hidden layer with non-linear activation functions easily learns the non-linear decision boundary required to solve XOR.
  ┌─────────────────────────────────────────────────────────────┐
  │                 3-Layer Simulator Architecture              │
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │   Input Layer             Hidden Layer          Output Layer│
  │  (2 Neurons)             (3 Neurons)             (1 Neuron) │
  │   ┌─────────┐            ┌─────────┐                        │
  │   │   x1    ├───────────►│ Neuron1 ├──┐                     │
  │   └─────────┘            ├─────────┤  │         ┌─────────┐ │
  │                          │ Neuron2 ├──┼────────►│  Output │ │
  │   ┌─────────┐            ├─────────┤  │         │   (y)   │ │
  │   │   x2    ├───────────►│ Neuron3 ├──┘         └─────────┘ │
  │   └─────────┘            └─────────┘                        │
  │                                                             │
  │   Initial State: All weights randomly initialized          │
  └─────────────────────────────────────────────────────────────┘
  • Input Layer: 2 Neurons corresponding to input features x1 and x2.
  • Hidden Layer: 3 Neurons equipped with non-linear activation functions.
  • Output Layer: 1 Neuron emitting predicted class probability ŷ.
  • Weights: Randomly initialized prior to training.

3. Detailed 10-Step Forward Pass and Backpropagation Execution

In an arithmetic simulator (e.g., mledict.com), executing a single training step breaks down into 10 sequential calculation steps across forward propagation, loss evaluation, and backpropagation:

  ┌─────────────────────────────────────────────────────────────┐
  │            10-Step Neural Network Execution Cycle           │
  ├─────────────────────────────────────────────────────────────┤
  │  FORWARD PASS:                                              │
  │  • Step 1 : Feed sample input row (e.g., x1 = 1, x2 = 1)   │
  │  • Step 2 : Compute Hidden Layer outputs (e.g., 0.35, 0.74, 0.53)│
  │  • Step 3 : Compute Output Layer prediction (e.g., y_hat = 0.25)│
  │  • Step 4 : Compute Cost / Loss (Target y = 0 vs. y_hat = 0.25)│
  │                                                             │
  │  BACKPROPAGATION PASS:                                      │
  │  • Step 5 : Compute Output Layer Error (e.g., Error = 0.049)│
  │  • Step 6 : Compute Hidden Layer Errors using derivatives   │
  │  • Step 7 : Compute Error w.r.t. Hidden-to-Output Weights   │
  │  • Step 8 : Compute Error w.r.t. Input-to-Hidden Weights    │
  │  • Step 9 : Update Hidden-to-Output Weights (Highlighted Red)│
  │  • Step 10: Update Input-to-Hidden Weights (Highlighted Green)│
  └─────────────────────────────────────────────────────────────┘

Step-by-Step Breakdown:

  1. Step 1 (Input Ingestion): The simulator selects the first row from the dataset (x1 = 1, x2 = 1, target y = 0) and feeds x1 = 1 and x2 = 1 into the input layer.
  2. Step 2 (Hidden Layer Forward Pass): The weighted sums plus biases are calculated for all 3 hidden neurons and passed through the activation function, outputting values such as 0.35, 0.74, and 0.53.
  3. Step 3 (Output Layer Forward Pass): The hidden outputs are multiplied by hidden-to-output weights to produce the network's predicted output (ŷ = 0.25).
  4. Step 4 (Cost Calculation): The loss function evaluates the error between the desired target (y = 0) and the predicted value (ŷ = 0.25).
  5. Step 5 (Output Layer Backpropagation): Backpropagation begins by computing the error derivative at the output layer (e.g., Output Error = 0.049).
  6. Step 6 (Hidden Layer Backpropagation): Using derivative chain rules, the output error is propagated backward to calculate error values across all 3 hidden layer neurons.
  7. Step 7 (Hidden-to-Output Weight Gradients): Error gradients are calculated with respect to the weights connecting the hidden layer to the output layer.
  8. Step 8 (Input-to-Hidden Weight Gradients): Error gradients are calculated with respect to the weights connecting the input layer to the hidden layer.
  9. Step 9 (Update Hidden-to-Output Weights): Gradient descent updates the hidden-to-output weights (visualized as turning red in the simulator interface).
  10. Step 10 (Update Input-to-Hidden Weights): Gradient descent updates the input-to-hidden weights (visualized as turning green in the simulator interface), completing one full forward and backward cycle.

  • One Step Forward: Advances the simulation by a single computational step (e.g., moving from hidden layer calculation to output layer prediction) for one sample row.
  • One Iteration Forward (Epoch): Executes the complete 10-step training pass across all 4 rows of the XOR dataset.
  • 1000 Iterations Forward: Automatically runs 1,000 complete epochs in rapid succession.
  • Convergence Result: After 1,000 iterations, the weights adjust from their initial random values to optimal values. Re-testing the input (x1 = 1, x2 = 1) yields a prediction of 0.49 (moving significantly closer toward the target 0 compared to initial untrained random outputs).

Lesson Q&A

Purpose of Web Simulators: Interactive web simulators (such as mledict.com and playground.tensorflow.org) allow students and developers to visualize the internal mechanics of a neural network. They display step-by-step mathematical calculations, weight updates, loss reductions, and real-time decision boundary formations.

Network Architecture in Simulation: The basic simulator utilizes a 3-layer feedforward architecture:

  • Input Layer: 2 neurons (accepting input features x1 and x2).
  • Hidden Layer: 1 hidden layer containing 3 neurons.
  • Output Layer: 1 neuron generating the final prediction y.

The Non-Linear XOR Problem Structure: The simulator models an Exclusive-OR (XOR) logic function:

  • If either x1 or x2 is 1 (and the other is 0), the target output y is 1.
  • If both inputs are 0 or both are 1, the target output y is 0.
  • Because XOR inputs cannot be separated using a straight line, a single-layer linear model fails. Solving XOR requires a multi-layer neural network utilizing non-linear activation functions.

The step-by-step execution in the simulator walks through 10 distinct operational steps across a single training instance:

Forward Pass (Steps 1–4):

  1. Input Feeding (Step 1): The first data row (e.g., x1=1, x2=1) is fed into the input layer.
  2. Hidden Layer Activation (Step 2): Weighted sums and activation outputs are calculated for the three hidden neurons (e.g., outputs 0.35, 0.74, 0.53).
  3. Output Generation (Step 3): The output neuron computes a predicted value (e.g., 0.25 against a target of 0).
  4. Cost/Loss Calculation (Step 4): The cost function measures the error between prediction (0.25) and target (0).

Backpropagation & Weight Updates (Steps 5–10):

  1. Output Error Calculation (Step 5): Calculates the error delta at the output layer (e.g., 0.049).
  2. Hidden Layer Error Propagation (Step 6): Propagates error backward through hidden neurons using derivatives.
  3. Gradients for Output Weights (Step 7): Computes error gradients for weights between the hidden and output layers.
  4. Gradients for Input Weights (Step 8): Computes error gradients for weights between the input and hidden layers.
  5. Updating Output Layer Weights (Step 9): Applies weight updates to output layer connections (highlighted in red in the simulator).
  6. Updating Input Layer Weights (Step 10): Applies weight updates to input-to-hidden layer connections (highlighted in green in the simulator).

Epoch Completion: Repeating these 10 steps across all 4 XOR data rows completes 1 Epoch. Fast-forwarding 1,000 iterations allows the network to rapidly reduce error and converge on correct outputs.

Advanced simulators like TensorFlow Playground (playground.tensorflow.org) allow users to experiment interactively with hyperparameter tuning, network topology, and dataset settings:

Hyperparameters & Tuning Controls:

  • Learning Rate (η): Adjusts the step size for weight updates during gradient descent.
  • Activation Function: Selects non-linear activation functions (e.g., Sigmoid, ReLU, Tanh) for hidden and output layers.
  • Regularization & Regularization Rate: Applies L1 or L2 regularization to control model complexity and prevent overfitting.
  • Problem Type: Switches between Classification (discrete categories) and Regression (continuous values).

Dataset & Input Controls:

  • Dataset Patterns: Selects from 2D dataset distributions (e.g., Circle, XOR, Gaussian, Spiral).
  • Train/Test Ratio: Controls the proportion of data split between training and validation sets.
  • Noise & Batch Size: Introduces noise to evaluate model robustness and adjusts batch size for mini-batch training.

Network Topology Controls:

  • Allows adding or removing hidden layers.
  • Allows increasing or decreasing the number of neurons per layer to observe real-time decision boundary learning.
