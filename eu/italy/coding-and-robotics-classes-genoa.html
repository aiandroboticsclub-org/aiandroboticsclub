Chapter 147 — Neural Network Training Explained Step by Step

1. Introduction & The Core Purpose of Training

In artificial neural networks, training refers to the process of teaching a model to minimize its prediction error and maximize its accuracy. A well-trained neural network is one that achieves minimal error when processing data.

The Human Learning Analogy

Neural network training mirrors the way humans learn. When humans are trained, they are shown examples repeatedly to improve their understanding and extract underlying patterns into memory. Similarly, a neural network must be exposed to input data repeatedly to learn data patterns and improve its predictive performance.

2. The 5-Step Training Pipeline Flow

The complete training execution pipeline follows a structured 5-step sequence:

  ┌─────────────────────────────────────────────────────────────┐
  │               5-Step Neural Network Pipeline                │
  ├─────────────────────────────────────────────────────────────┤
  │  Step 1: Parameter Initialization                           │
  │     • Initialize weights (w) and biases (b) using           │
  │       random number generation.                             │
  │                                                             │
  │  Step 2: Forward Pass                                       │
  │     • Feed training data into input layer ──► Moves toward  │
  │       output layer to calculate predictions.                │
  │                                                             │
  │  Step 3: Loss Calculation                                   │
  │     • Compare predicted values (ŷ) against actual           │
  │       annotated labels (y) to extract the loss.             │
  │                                                             │
  │  Step 4: Backpropagation & Weight Updates                   │
  │     • Compute gradients and adjust weights using Gradient   │
  │       Descent (w = w − η · ∂L/∂w).                          │
  │                                                             │
  │  Step 5: Epoch Iterations                                   │
  │     • Repeat the loop over multiple full data passes.       │
  └─────────────────────────────────────────────────────────────┘
  1. Weight & Bias Initialization: Connection weights (w) and biases (b) are initialized using random number generation.
  2. Forward Pass: Training data inputs enter through the input layer and flow forward toward the output layer, where the network calculates its predictions.
  3. Loss Computation: The network's predicted output values are compared against the ground-truth annotated labels provided in the training data to calculate the loss.
  4. Backpropagation & Parameter Adjustments: The loss gradient is calculated, and the network uses the Gradient Descent algorithm to adjust weights and biases across all layers to reduce prediction error.
  5. Iterative Epoch Loops: Steps 2 through 4 are repeated across multiple full dataset iterations called epochs until the loss function is minimized and accuracy is maximized.

3. Data Splitting Strategies for Generalization

To evaluate how well a model generalizes to new, unseen data, the raw dataset is split into distinct subsets.

  │ • Training Set  : 60%         │ • Used to learn weights &   │
  │                               │   biases.                   │

  │                               │   parameters.               │
  │ • Testing Set   : 20%         │ • Used to evaluate final    │
  │                               │   unseen performance.       │
  ├───────────────────────────────┼─────────────────────────────┤
  │ 2-Set Alternative Split       │                             │

  │ • Testing Set   : 30%         │ • Tests final accuracy.     │
  └───────────────────────────────┴─────────────────────────────┘

A. Set Definitions & Roles:

  • Training Set: Used directly by the network to learn optimal weights and biases during training.
  • Validation Set: Used by data scientists to tweak and tune hyper-parameters.
  • Testing Set: Kept completely separate during training; used to measure final model performance and testing error on unseen data.

B. Industry Rules of Thumb for Data Ratios:

  • 3-Set Partitioning: 60% Training, 20% Validation, and 20% Testing.
  • 2-Set Partitioning: 70% Training and 30% Testing.

Concrete Numerical Example:

Suppose a training dataset contains 1,000 total samples:

  • Selected Batch Size: 100 samples.
  • Total Batches Generated: 1000 / 100 = 10 batches.
  • Execution: Processing all 10 batches through a forward and backward pass once constitutes 1 complete Epoch.

The Weight Update Equation:

The learning rate (η) is a hyper-parameter that controls the step size of weight updates during gradient descent:

w = w − η · ∂L/∂w

Where η represents the learning rate, and ∂L/∂w represents the error gradient with respect to weight w.

  ┌─────────────────────────────────────────────────────────────┐
  │            Learning Rate (η) Impact Analysis                │
  ├───────────────────────────────┬─────────────────────────────┤
  │ Learning Rate Setting         │ Behavioral Impact & Results │
  ├───────────────────────────────┼─────────────────────────────┤
  │ Too High (η = 0.1)            │ Takes 10% steps; overshoots │
  │                               │ target, causing unstable,   │
  │                               │ divergent training.         │
  ├───────────────────────────────┼─────────────────────────────┤
  │ Too Low (η = 0.0001)          │ Learning is extremely slow; │
  │                               │ may fail to converge within │
  │                               │ allocated epochs.           │
  ├───────────────────────────────┼─────────────────────────────┤
  │ Optimal (η = 0.01)            │ Fast learning with smooth,  │
  │                               │ stable convergence.         │
  └───────────────────────────────┴─────────────────────────────┘

Numerical Comparison of Learning Rates:

  • High Learning Rate (η = 0.1): Makes 10% updates per step. This step size is too large, causing the model to overshoot target values, destabilize training, and diverge.
  • Excessively Low Learning Rate (η = 0.0001): Makes tiny updates. Learning becomes sluggish and takes excessive compute time, failing to converge within specified epochs.
  • Optimal Learning Rate (η = 0.01): Provides fast training while ensuring smooth, stable convergence. Recommended starting values are 0.01 or 0.001.

Lesson Q&A

  1. Weight & Bias Initialization: The training process begins by initializing the network's weights and biases using random number generation.
  2. Forward Pass: Training data is fed into the network and moves sequentially from the input layer toward the output layer to compute predictions.
  3. Loss Calculation: The network's predicted output is compared against the actual annotated target labels to calculate the prediction error (loss).
  4. Backpropagation & Weight Adjustment: The calculated loss is used to compute gradients across all layers. Using the Gradient Descent algorithm, the network adjusts its weights and biases according to the update formula w = w − η · ∂L/∂w.
  5. Iterations & Epochs: This complete cycle is repeated across multiple iterations and passes (epochs) over the training data to minimize the loss function and maximize prediction accuracy.

Dataset Splitting & Ratios:

  • Training Set (60% or 70%): Used directly by the network to learn weights and biases.
  • Validation Set (20%): Used by developers to tune hyperparameters and tweak network settings.
  • Testing Set (20% or 30%): Kept completely separate during training to evaluate final model accuracy, error, and generalization capability on unseen data.
  • Rules of Thumb: Use a 60% / 20% / 20% split for Train/Validation/Test, or a 70% / 30% split if only using Training and Testing sets.

Epochs vs. Batches:

  • Epoch: A complete single pass of the training pipeline over the entire dataset.
  • Batch: A smaller subset of the training dataset used to perform incremental updates (mini-batch training), which improves training stability and speeds up processing.
  • Example: A dataset of 1,000 samples divided into a batch size of 100 yields 10 batches per epoch.

Parameters vs. Hyperparameters:

  • Parameters: Variables that the neural network learns automatically during training (e.g., weights and biases).
  • Hyperparameters: Settings explicitly set by a human before training begins (e.g., learning rate, batch size).

Impact of Learning Rate (η):

  • Too High (≈ 0.1): Takes oversized update steps that overshoot target weights, causing training instability and divergence.
  • Too Low (≈ 0.0001): Results in extremely slow learning that takes excessive time and may fail to converge within the allotted epochs.
  • Optimal Rate (≈ 0.01): Provides fast and smooth convergence toward optimal accuracy.

Evaluation Metrics:

  • Classification: Evaluated using Accuracy, Precision, Recall, F1 Score, and Confusion Matrices.
  • Regression: Evaluated using Mean Squared Error (MSE), Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE).
