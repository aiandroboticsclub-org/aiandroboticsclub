Chapter 166 — YOLO Object Detection Explained: How AI Finds Objects in Images

1. Introduction & Core Object Detection Concepts

In computer vision, visual recognition tasks are divided into two distinct sub-problems: Object Classification and Object Localization.

  • Object Classification: Determines what object is present in an image, which is framed as a classification problem.
  • Object Localization: Determines where the object is located and its spatial dimensions, which is framed as a continuous regression problem.
  ┌─────────────────────────────────────────────────────────────┐
  │                 Object Recognition Framework                │
  ├───────────────────────────────┬─────────────────────────────┤
  │ Object Classification         │ Object Localization         │
  ├───────────────────────────────┼─────────────────────────────┤
  │ • Identifies WHAT object is   │ • Pinpoints WHERE the object│
  │   present in the image.       │   is located.               │
  │ • Categorizes class labels.   │ • Predicts bounding box     │
  │                               │   coordinates and size.     │
  └───────────────────────────────┴─────────────────────────────┘

Core YOLO Architecture:

The YOLO (You Only Look Once) framework solves both classification and localization simultaneously in a single forward pass. Its architecture consists of two primary modules:

  1. CNN Backbone: A deep feature extraction backbone such as DarkNet, MobileNet, or ResNet.
  2. Detection Head: A fully connected regression head that outputs bounding box predictions.

Bounding Box Representation:

A bounding box encloses a detected object, providing both its spatial location and its size. By default, YOLO models come pre-trained on the COCO dataset, which contains 80 distinct object classes. When target objects fall outside these default 80 classes, developers must build a custom dataset, annotate images with bounding boxes, and fine-tune YOLO.

3. Dataset Creation & Label Annotation Structure

Label Representation (5 Output Parameters):

To train a YOLO-like model, every object label is annotated using a 5-element vector:

Label Vector = [x_center, y_center, w, h, class]
  • x_center: Horizontal coordinate of the bounding box center.
  • y_center: Vertical coordinate of the bounding box center.
  • w: Spatial width of the bounding box.
  • h: Spatial height of the bounding box.
  • class: Target object class ID (e.g., binary class 1).

# Construct YOLO-like CNN Architecture
model = models.Sequential([
    # First Convolutional Block
    layers.Conv2D(16, (3, 3), activation='relu', input_shape=(128, 128, 3)),
    layers.MaxPooling2D((2, 2)),

    # Second Convolutional Block
    layers.Conv2D(32, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),

    # Third Convolutional Block
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),

    # Detection Head
    layers.Flatten(),
    layers.Dense(128, activation='relu'),
    layers.Dense(5, activation='sigmoid')  # Outputs: [x, y, w, h, class]
])

# =====================================================================
# Complete YOLO Object Detection Script (Topic 166)
# =====================================================================

import tensorflow as tf
from tensorflow.keras import layers, models
import numpy as np
import cv2
import matplotlib.pyplot as plt

# 1. Dataset Generation Function
def create_dataset(num_samples=200):
    images = []
    labels = []
    img_size = 128

    for _ in range(num_samples):
        # Create black canvas (128x128x3 uint8)
        img = np.zeros((img_size, img_size, 3), dtype=np.uint8)

        # Generate random bounding box coordinates
        x_min = np.random.randint(10, 60)
        y_min = np.random.randint(10, 60)
        w = np.random.randint(20, 50)
        h = np.random.randint(20, 50)

        # Draw white rectangle on canvas
        cv2.rectangle(img, (x_min, y_min), (x_min + w, y_min + h), (255, 255, 255), -1)

        # Calculate normalized coordinates
        x_center = (x_min + w / 2.0) / img_size
        y_center = (y_min + h / 2.0) / img_size
        norm_w = w / float(img_size)
        norm_h = h / float(img_size)
        cls_id = 1.0  # Class 1

        images.append(img / 255.0)  # Normalize pixel values
        labels.append([x_center, y_center, norm_w, norm_h, cls_id])

    return np.array(images, dtype=np.float32), np.array(labels, dtype=np.float32)

# 2. Generate Dataset and Split 80/20
X, Y = create_dataset(200)
split_idx = int(0.8 * len(X))
X_train, X_test = X[:split_idx], X[split_idx:]
Y_train, Y_test = Y[:split_idx], Y[split_idx:]

# 3. Construct YOLO-like Architecture
model = models.Sequential([
    layers.Conv2D(16, (3, 3), activation='relu', input_shape=(128, 128, 3)),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(32, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),
    layers.Flatten(),
    layers.Dense(128, activation='relu'),
    layers.Dense(5, activation='sigmoid')
])

# 4. Compile and Display Model Summary
model.compile(optimizer='adam', loss='mse')
model.summary()

# 5. Train Model for 10 Epochs
history = model.fit(X_train, Y_train, epochs=10, batch_size=8, validation_split=0.2)

# 6. Evaluate Model Test Loss
test_loss = model.evaluate(X_test, Y_test, verbose=0)
print(f"\nFinal Test Loss: {test_loss:.6f}")

# 7. Intersection over Union (IoU) Calculation Function
def compute_iou(boxA, boxB):
    # Convert normalized [x_c, y_c, w, h] to corner coordinates
    xA1 = boxA[0] - boxA[2]/2.0
    yA1 = boxA[1] - boxA[3]/2.0
    xA2 = boxA[0] + boxA[2]/2.0
    yA2 = boxA[1] + boxA[3]/2.0

    xB1 = boxB[0] - boxB[2]/2.0
    yB1 = boxB[1] - boxB[3]/2.0
    xB2 = boxB[0] + boxB[2]/2.0
    yB2 = boxB[1] + boxB[3]/2.0

    # Intersection coordinates
    xI1 = max(xA1, xB1)
    yI1 = max(yA1, yB1)
    xI2 = min(xA2, xB2)
    yI2 = min(yA2, yB2)

    inter_area = max(0, xI2 - xI1) * max(0, yI2 - yI1)
    boxA_area = (xA2 - xA1) * (yA2 - yA1)
    boxB_area = (xB2 - xB1) * (yB2 - yB1)

    union_area = boxA_area + boxB_area - inter_area
    return inter_area / union_area if union_area > 0 else 0.0

# 8. Test Predictions & IoU Evaluation
predictions = model.predict(X_test[:5])
for i in range(5):
    iou = compute_iou(Y_test[i][:4], predictions[i][:4])
    print(f"Sample {i+1} - True Box: {Y_test[i][:4]}, Pred Box: {predictions[i][:4].round(3)}, IoU: {iou:.3f}")

Lesson Q&A

Dual Problems Solved: YOLO addresses both object detection (a classification problem) and object localization (a regression problem) in a single step. While classification identifies what the object is, localization determines where it is located and its size using bounding boxes.

Prediction Output Format: The final output layer outputs 5 core parameters for each prediction vector:

  1. x-center: The horizontal center coordinate of the object.
  2. y-center: The vertical center coordinate of the object.
  3. Width (w): The width of the bounding box.
  4. Height (h): The height of the bounding box.
  5. Class: The predicted object class label.

Default Pre-trained Dataset: By default, YOLO models are pre-trained on the COCO dataset, which contains 80 distinct object classes. If target objects fall outside these 80 classes, a custom dataset must be created, annotated with bounding boxes, and used to fine-tune the model.

Feature Extraction Backbone (Repeating Conv2D & MaxPool2D Blocks):

  • Layer 1: Conv2D with 16 filters (3 × 3 kernel, ReLU activation, input shape (128, 128, 3)), yielding 448 trainable parameters. Followed by MaxPooling2D downsampling to (63, 63, 16).
  • Layer 2: Conv2D with 32 filters (3 × 3 kernel, ReLU activation), yielding 4,640 parameters. Followed by MaxPooling2D downsampling to (30, 30, 32).
  • Layer 3: Conv2D with 64 filters (3 × 3 kernel, ReLU activation), yielding 18,496 parameters. Followed by MaxPooling2D downsampling to (14, 14, 64).

Classification & Localization Head:

  • Flatten Layer: Converts multidimensional feature maps into a 1D vector of length 12,544.
  • Hidden Dense Layer: 128 neurons with ReLU activation, adding ~1.6 million parameters.
  • Output Dense Layer: 5 output nodes with Sigmoid activation to output the 5 bounding box and class values.

Total Parameters & Memory: The model contains 1,629,889 total trainable parameters (~6.22 MB memory footprint). It is compiled using the Adam optimizer and Mean Squared Error (MSE) loss function.

Training Execution & Loss Reduction: The model is trained over 10 epochs using a GPU instance on Google Colab. Training loss decreases from 0.03 down to 0.00157, reaching a final test loss of 0.0012 on unseen test data.

Intersection over Union (IoU): IoU is the primary performance evaluation metric used to evaluate bounding box alignment. It measures the spatial overlap between the predicted bounding box and the ground-truth bounding box:

IoU = Intersection Area / Union Area

Performance Evaluation: Higher IoU values reflect better spatial localization and object detection accuracy. Across test predictions, individual samples achieved IoU scores ranging from 0.57 to 0.87 (with 0.87 representing the top-performing sample).
